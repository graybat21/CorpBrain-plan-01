# 시장 A: 데이터 전처리 및 환경 세팅 시장 (5Forces 심층 분석)

## 1. 시장 개요 (Market Definition)
'비정형 데이터 전처리 및 환경 세팅' 시장은 기업 내 산재한 날것의 데이터(PDF, 스캔본, 이메일, 웹페이지 등)를 파싱(Parsing)하고 노이즈를 제거하여 LLM 및 RAG 시스템이 이해할 수 있는 벡터/구조화 데이터(JSON 등)로 변환하는 기술 기반 시장입니다.

## 2. 5Forces 심층 분석

### 2.1 기존 경쟁자 간의 경쟁 (Rivalry) - [위협 수준: 높음]
*   **핵심 플레이어**: Unstructured.io (글로벌 1위, 의미 기반 청킹 및 파싱), Upstage (국내 1위, 고도의 OCR 및 표 인식).
*   **경쟁 양상**: API 서비스 중심의 B2B 데이터 파이프라인 경쟁이 치열합니다. 정확도(표, 차트 추출)와 처리 속도가 핵심 경쟁력입니다.
*   **CorpBrain의 위치**: CorpBrain은 이 시장의 솔루션을 '판매'하는 것이 아니라 '활용'하는 위치에 가깝습니다. 전처리 자체를 비즈니스 모델로 삼는 경쟁사들과 직접 경쟁할 필요가 없습니다.

### 2.2 신규 진입자의 위협 (New Entrants) - [위협 수준: 높음]
*   **진입 장벽**: LangChain, LlamaIndex 등 오픈소스 데이터 로더(Data Loader) 기술의 발전으로 누구나 기본적인 전처리 파이프라인을 구축할 수 있어 진입 장벽이 급격히 낮아졌습니다.
*   **실질적 해자**: 단순 텍스트 추출은 쉬우나, 복잡한 다단 문서나 손상된 스캔본을 정확히 파싱하는 'Vision AI' 결합 기술은 여전히 고난도입니다.

### 2.3 대체재의 위협 (Substitutes) - [위협 수준: 중간]
*   **대체 수단**: 직원이 직접 문서를 복사하여 텍스트 파일로 붙여넣는 수동 작업, 또는 AWS Textract 등 기존의 범용 클라우드 OCR 서비스.
*   **방어 전략**: 수동 작업은 확장성(Scalability)이 없으므로, 대량 문서 처리를 위해서는 전용 파이프라인이 필수적입니다.

### 2.4 공급자의 교섭력 (Suppliers) - [위협 수준: 높음]
*   **주요 공급자**: OpenAI(Vision API), 클라우드 기반 GPU 제공업체.
*   **종속성 리스크**: 전처리를 위해 타사의 고성능 Vision API에 의존할 경우 비용(API Call)이 기하급수적으로 증가할 수 있습니다.

### 2.5 구매자의 교섭력 (Buyers) - [위협 수준: 중간]
*   **타겟 고객**: 자사 RAG 시스템을 구축하려는 엔터프라이즈 기업의 IT 부서 및 AI 개발자.
*   **동학**: 구매자는 다양한 전처리 오픈소스와 상용 API 중 성능과 비용을 저울질하여 선택할 권리가 있습니다.

## 3. CorpBrain의 전략적 대응 (Strategic Positioning)
*   **Make or Buy 전략**: CorpBrain은 10인 미만 기업을 위한 '완제품 앱'입니다. 문서 파싱 기술(OCR 등)을 바닥부터 자체 개발(Make)하는 것은 리소스 낭비입니다. Unstructured 오픈소스나 Upstage API를 파이프라인의 일부로 차용(Buy/Use)하여 개발 속도를 극대화해야 합니다.
*   **경쟁 우위(Moat)**: 전처리는 도구일 뿐입니다. 파싱된 데이터를 단순히 Vector DB에 넣는 데 그치지 않고, RL 알고리즘을 통해 **'지식 간의 충돌을 해결하고 하나의 위키 트리로 엮어내는(Merging)'** 상위 레벨의 논리 구조가 CorpBrain의 진짜 무기입니다.
