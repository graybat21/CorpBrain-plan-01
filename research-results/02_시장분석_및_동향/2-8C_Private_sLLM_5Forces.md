# 시장 C: 프라이빗 sLLM 보안 인프라 시장 (5Forces 심층 분석)

## 1. 시장 개요 (Market Definition)
기업의 핵심 기밀 데이터 유출을 막기 위해 퍼블릭 클라우드(OpenAI API 등)를 사용하지 않고, 기업 내부 망(폐쇄망)이나 물리적 사내 서버에서 독립적으로 구동되는 경량화 LLM(sLLM)과 이를 담는 하드웨어(어플라이언스) 시장입니다.

## 2. 5Forces 심층 분석

### 2.1 기존 경쟁자 간의 경쟁 (Rivalry) - [위협 수준: 중간]
*   **핵심 플레이어**: Saltlux (LUXIA-ON 어플라이언스), 각종 대형 SI 기업군.
*   **경쟁 양상**: 소프트웨어 모델 성능뿐만 아니라, 하드웨어 수급 및 설치, 유지보수 네트워크 등 '오프라인/인프라 역량'이 매우 중요합니다.
*   **CorpBrain의 위기**: 솔트룩스 등은 공공/금융 기관을 타겟으로 한 수천만 원~수억 원대 서버 구축 비즈니스를 수행합니다.

### 2.2 신규 진입자의 위협 (New Entrants) - [위협 수준: 낮음]
*   **진입 장벽**: 하드웨어 수급(NVIDIA GPU 등)과 물리적 서버 세팅 역량이 필요하여, 일반적인 순수 S/W 스타트업이 쉽게 진입하기 어렵습니다.

### 2.3 대체재의 위협 (Substitutes) - [위협 수준: 높음]
*   **대체 수단**: 강력한 보안 컴플라이언스를 갖춘 엔터프라이즈용 퍼블릭 클라우드 API (Microsoft Azure OpenAI 등).
*   **분석**: "클라우드는 해킹당한다"는 인식보다 "Azure나 AWS가 우리 사내 망보다 안전하다"는 인식이 확산될 경우 프라이빗 서버 시장 자체가 축소될 수 있습니다.

### 2.4 공급자의 교섭력 (Suppliers) - [위협 수준: 매우 높음]
*   **주요 공급자**: GPU 제조사 (NVIDIA 압도적 독점), 오픈소스 파운데이션 모델 (Meta Llama, Google Gemma).
*   **분석**: 하드웨어 수급 원가(GPU 가격)가 폭등하면 비즈니스 모델 전체가 무너질 수 있는 치명적 약점을 가집니다.

### 2.5 구매자의 교섭력 (Buyers) - [위협 수준: 높음]
*   **타겟 고객**: 딥테크, 법률, 특허, 금융 등 극도로 보안에 민감한 기업.
*   **동학**: 구축형(On-premise) 솔루션은 초기 도입 비용(CAPEX)이 막대하므로 구매 결정을 내리기까지 오랜 시간이 걸립니다.

## 3. CorpBrain의 전략적 대응 (Strategic Positioning)
*   **극소형 BYOC & HaaS 전략**: 타겟인 10인 미만 기업에게 수천만 원대 서버를 팔 수는 없습니다. CorpBrain은 고객이 보유한 일반적인 '게이밍 PC(예: RTX 4090 장착)'를 서버로 활용하는 **초경량 BYOC(Bring Your Own Cloud)** 전략을 채택해야 합니다.
*   **하드웨어 구독 (HaaS)**: PC가 없는 고객에게는 고가의 엔터프라이즈 서버가 아닌, 하이엔드 워크스테이션을 월 구독료(HaaS)로 렌탈해주어 초기 도입 자본금(CAPEX)을 제로화하는 비즈니스 모델 혁신이 필수적입니다.
